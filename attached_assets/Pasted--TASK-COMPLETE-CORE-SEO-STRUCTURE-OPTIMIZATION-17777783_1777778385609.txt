SECTION 5: CHATBOT LAZY LOAD (PERFORMANCE FIX)
--------------------------------------------------

Current issue:
Chatbot loads immediately → slows site

--------------------------------------------------

FIX:

1. REMOVE chatbot load on page start

2. LOAD chatbot ONLY:

- on user click

--------------------------------------------------

IMPLEMENT:

  if (!window.chatLoaded) {
    loadChatbot();
