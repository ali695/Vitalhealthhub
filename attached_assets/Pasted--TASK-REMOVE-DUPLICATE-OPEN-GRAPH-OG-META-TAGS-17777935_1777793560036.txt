--------------------------------------------------
TASK: REMOVE DUPLICATE OPEN GRAPH (OG) META TAGS
--------------------------------------------------

GOAL:
Ensure every page has ONLY ONE correct set of Open Graph tags.

Duplicate OG tags confuse search engines and break social sharing previews.

--------------------------------------------------
SECTION 1: DETECT DUPLICATES
--------------------------------------------------

Scan the <head> of every page and identify duplicate occurrences of:

- <meta property="og:title">
- <meta property="og:description">
- <meta property="og:image">
- <meta property="og:url">

If any tag appears more than once → mark it as duplicate.

--------------------------------------------------
SECTION 2: REMOVE ALL DUPLICATES
--------------------------------------------------

For each OG property:

❌ REMOVE all duplicate entries  
✔ KEEP only ONE clean version

Example:

❌ WRONG:
<meta property="og:title" content="...">
<meta property="og:title" content="...">

✔ CORRECT:
<meta property="og:title" content="...">

--------------------------------------------------
SECTION 3: STANDARDIZE OG STRUCTURE
--------------------------------------------------

Each page must contain EXACTLY this structure:

<meta property="og:title" content="Page Title | VitalHealth Hub">
<meta property="og:description" content="Short, engaging description of the page (max 160 chars)">
<meta property="og:type" content="website">
<meta property="og:url" content="https://vitalhealthhub.org/page-url">
<meta property="og:image" content="https://vitalhealthhub.org/images/og-default.jpg">

--------------------------------------------------
SECTION 4: ENSURE UNIQUENESS PER PAGE
--------------------------------------------------

Each page should have:

- unique og:title
- unique og:description
- correct og:url (matching canonical)

Do NOT reuse homepage values for all pages.

--------------------------------------------------
SECTION 5: ALIGN WITH CANONICAL
--------------------------------------------------

Ensure:

<link rel="canonical" href="https://vitalhealthhub.org/page-url">

AND

<meta property="og:url" content="https://vitalhealthhub.org/page-url">

✔ MUST MATCH EXACTLY

--------------------------------------------------
SECTION 6: REMOVE CONFLICTING TAGS
--------------------------------------------------

Check for:

- duplicate Twitter tags
- conflicting OG vs Twitter values

Ensure consistency:

twitter:title = og:title  
twitter:description = og:description  
twitter:image = og:image  

--------------------------------------------------
SECTION 7: CLEAN HEAD STRUCTURE
--------------------------------------------------

Ensure <head> contains:

✔ ONE og:title  
✔ ONE og:description  
✔ ONE og:image  
✔ ONE og:url  
✔ NO duplicates  

--------------------------------------------------
SECTION 8: VALIDATION
--------------------------------------------------

After cleanup:

✔ No duplicate OG tags exist  
✔ Social previews work correctly  
✔ SEO signals are clean  
✔ Page source is optimized  

--------------------------------------------------
FINAL OUTPUT REQUIRED
--------------------------------------------------

1. List all duplicate OG tags found  
2. Confirm duplicates removed  
3. Confirm:

"All Open Graph tags are unique and correctly optimized"
