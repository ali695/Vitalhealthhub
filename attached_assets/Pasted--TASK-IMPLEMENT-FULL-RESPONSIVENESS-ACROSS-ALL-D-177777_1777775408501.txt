--------------------------------------------------
TASK: IMPLEMENT FULL RESPONSIVENESS ACROSS ALL DEVICES
--------------------------------------------------

Make the entire website (VitalHealth Hub) fully responsive across ALL screen sizes, not just mobile.

Apply this to:

- homepage
- blog pages
- calculator pages
- tools pages
- quiz pages
- admin dashboard

--------------------------------------------------
GLOBAL GOAL
--------------------------------------------------

Create a layout system that:

- adapts smoothly to all screen sizes
- never breaks
- feels premium on every device
- avoids stretched or cramped layouts

--------------------------------------------------
SECTION 1: BREAKPOINT SYSTEM (VERY IMPORTANT)
--------------------------------------------------

Use proper breakpoints:

- 320px → small mobile
- 480px → large mobile
- 768px → tablet
- 1024px → small laptop
- 1366px → laptop
- 1440px → desktop
- 1920px → large desktop
- 2560px+ → ultra-wide screens

--------------------------------------------------
SECTION 2: CONTAINER SYSTEM
--------------------------------------------------

Use responsive max-width containers:

- mobile: 100%
- tablet: max-width 720px
- laptop: max-width 1100px
- desktop: max-width 1200px
- large desktop: max-width 1400px

Center all content:

margin: 0 auto;

--------------------------------------------------
SECTION 3: GRID SYSTEM
--------------------------------------------------

Use flexible grids:

Desktop:
- 3–4 columns

Tablet:
- 2 columns

Mobile:
- 1 column

Use:

grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));

--------------------------------------------------
SECTION 4: TYPOGRAPHY SCALING
--------------------------------------------------

Make text responsive:

h1:
- desktop: large
- tablet: medium
- mobile: smaller

Use fluid sizing:

clamp(min, vw, max)

Example:
font-size: clamp(24px, 4vw, 48px);
