--------------------------------------------------
SECTION 12: FULL RESPONSIVE SYSTEM (ALL DEVICES)
--------------------------------------------------

GOAL:
Make the entire website fully responsive across:

✔ Mobile (320px–767px)
✔ Tablet (768px–1023px)
✔ Laptop (1024px–1440px)
✔ Large screens (1440px+)

NO layout should break on ANY screen.

--------------------------------------------------
BREAKPOINT SYSTEM (MANDATORY)
--------------------------------------------------

Use consistent breakpoints:

Mobile:
max-width: 767px

Tablet:
768px – 1023px

Desktop:
1024px+

Large:
1440px+
